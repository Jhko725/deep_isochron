# `plotting` — the notebook's model-comparison helpers into the library

## Summary

`prototype_analysis.ipynb` had grown nine helpers and four figures for comparing a
trained model with the reference phase field and the AUTO isochrons, and the review of
`auto-isochrons` said the notebook's plots were the ones to keep and that its helpers
hinted at the methods the library lacked. The grilling round of 2026-10-29 (Project
document `claude/plotting-plan-2026-10-29.md`, nine points, all yes) placed each helper:
on the model contract, in a new `analysis/model.py`, beside `find_limit_cycle`, on
`Isochron`, in `training/evaluation.py`, or in `plotting/`. This branch moves them, with
one test per figure and a law per method, and the notebook calls the library.

Reversible: no file format, hash or checkpoint changes; the notebook's cells can be
restored from `git log`.

## Design

- **`equilibrium()` is the conjugacy model's, not the contract's.** The plan put it on
  the contract as "the image of the latent origin", but the autoencoder's latent is the
  unit circle times a deviation variable (`normalize_phase_plane`), with no point for
  the phaseless set, so a contract method would have had to raise. `isochron_coordinate` and
  `isochron` are on the contract, since both models have them; `plot_isochron_hairpins`
  types its model as `ConjugateLatentDynamics`. Alternative rejected: `equilibrium` on
  the contract raising `NotImplementedError` for the autoencoder, a contract that is
  not one.
- **`isochron_coordinate` beside `isochron`.** The notebook's `matched_points` needed the
  latent radii of given points and reached into `model.bijection` for them; the
  deletion test says the method earns its place, since without it every caller reaches
  in. Its normalization is the model's own, as `amplitude`'s is. The review found the
  first name, `latent_radius`, unclear (it read as the limit cycle), so the method is
  named for what it is, the coordinate along the isochron, and its docstring states the
  law ``isochron_coordinate(isochron(θ, r)) == r``, the two normalizations (1 on the
  cycle for the conjugacy model, 0 for the autoencoder) and that the limit cycle is
  `cycle_point`.
- **`phase_offset`, not `phase_origin`.** The value is used as `offset` everywhere else
  (`PhaseAlignment.offset`, `align_phases(offset=)`), and one quantity carries one name.
  `phase_sense` keeps its name: `LimitCycle.orientation()` is the geometric orientation
  of the planar orbit, a different quantity.
- **`phase_sense` from the model's own prediction**, the sign of the wrapped phase change
  over a thousandth of the reference period, rather than the notebook's
  `latent_dynamics.omega()`, which only the conjugacy model has.
- **`align_phases` beside `phase_amplitude_agreement`**, which already compares phases
  up to orientation and offset through the circular standard deviation; the new
  function is the explicit form (sense, offset, residual field, RMS) that a plot needs,
  and takes the offset from `phase_offset` when a cycle is at hand, so the metric and
  the figure agree by construction. `Evaluator` does not report it yet: that needs a
  reference field in the evaluation data, which item M will add.
- **`find_equilibrium` reports convergence rather than raising**, as `nearest_cycle_time`
  does, and counts converged only when the residual is below `RESIDUAL_TOL` as well as
  the step, since Optimistix's Newton stops on the step.
- **The figures return their numbers and print nothing**: `PhaseComparison`,
  `HairpinMatch` and the gap arrays carry what the notebook printed, and the notebook
  prints them in Joon's wording.
- **`plot_isochron_match` clips to the foliation's bounding box**, not the notebook's
  plotting window, so it needs no grid; `plot_isochron_hairpins` frames the full panel
  on the isochron's own extent for the same reason.
- **The container rule.** The review asked where the boundary between `NamedTuple`,
  dataclass and `eqx.Module` lies. The answer is the equinox ecosystem's axis, "pytree
  or not": a value that any transform sees is an `eqx.Module`, a value kept out of
  tracing is a frozen dataclass of NumPy or Python values, and a `NamedTuple` is allowed
  only where the tuple structure is the interface (the `*Params` bundles). The rule is
  in `coding-standards.md` § Containers, recorded on ADR-0012 whose Decision 3 it
  sharpens, and checked by `scripts/checks/check_containers.py`, which flags an `Array`
  field in a frozen dataclass, an `Array` in a static field, and a `NamedTuple` not
  named `*Params`. The check leaves mutable dataclasses alone, since the rule reserves
  them for Hydra schemas and stateful services such as `Evaluator`, and reads an
  `Array` inside a `Callable[...]` as a signature.
- **The four jit-side results by the rule.** `ShootingResult`, `ShootingArgs` and
  `PeriodicSchur` were `NamedTuple`s carried through jitted code and are `eqx.Module`s;
  construction stays positional and every use was already attribute access.
  `PeriodicSchur`'s fields are now `R, Q, signs`: as a module the class is checked by
  the jaxtyping hook in field order, and `Q`'s ``m+1`` axis must come after `R` binds
  ``m``. Review round 2 asked for the mathematical order `Q, R` through a hand-written
  `__init__`; a probe showed that the hook checks shapes only through the generated
  `__init__`, so a custom one in either order passes a `Q` of the wrong shape, and the
  checked order stays. `FixedPointIteration` is a host-side record of NumPy and is a frozen
  dataclass, as `Cycle` is. `PhaseAlignment.residual`, the one `Array` in a dataclass,
  is NumPy.
- **The five handles by the rule.** `AutoSolution`, `AutoHandle`, `Idx`, `SymbolicODE`
  and `CompiledExpressions` were `NamedTuple`s that no code used as tuples (the one
  `_asdict` is `dataclasses.asdict`) and are frozen dataclasses. `CompiledExpressions`
  is a dataclass rather than an `eqx.Module` because it lives as a `ClassVar` that
  nothing flattens.
- **A static field never holds an `Array`.** The `raw` of `ScalarChain` and
  `OffsetedBijection` is `None` by construction and was `eqx.field(static=True)` under
  an `Array` annotation. `ty` refuses to narrow the `AbstractVar` annotation to
  `None`, so the field is a plain `None` leaf instead: an empty pytree node, so
  tracing, `eqx.partition` and serialization are unchanged.
- **`hairpins` keeps its extrema line.** The review suggested a `local_extrema`
  function; with one adopter, a comment names the test instead.
- **`configs/phase_field/` is its own group**, composed by `compose_group`, rather than a
  block of the isochron configs: `t_end` is `phase_grid`'s, and the isochron hash was
  having to exclude it (ADR-0011 History).

## Bugs fixed

- The notebook imported `isochron_file` from `experiment.isochrons`, which the
  structured-config round replaced by `IsochronConfig.file()`, and read
  `cfg.phase_field.t_end`, which the same round removed from the isochron configs; both
  cells would have failed on the next run.
- `tests/test_isochron.py`'s hand foliation called its radial lines Hopf's isochrons;
  with ``w0 != w`` Hopf's isochrons are logarithmic spirals (``h(r) = (w − w0)/a · ln
  r``). Nothing had compared them with the form's phase before; the form now has
  ``w0 == w``.
